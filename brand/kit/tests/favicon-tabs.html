Favicon on browser tabs

The 16 px favicon at its real size (16 CSS px) on approximate light and dark tab colours of Chrome, Firefox and Safari. Each strip: the active tab, then a background tab. SVG = icons/favicon.svg (the 16 px cut; the dark-mode teal when the browser is dark). ICO/PNG = the fallback for browsers without SVG favicons (light-mode teal everywhere). Tile = the usual alternative, the mark shrunk onto a teal tile, for comparison only. Screenshots at 1x and 2x.

Classic teal (recommended): light #1B6E66, dark #5FB3A9
