# Secrets as TPM-sealed systemd credentials

App secrets are generated by HomersLab and stored as systemd credentials:
- sealed to the machine's TPM, or with a root-only key where there is no TPM;
- decrypted only when the app's service starts;
- handed to its containers as files.

It is a standard mechanism that keeps working without HomersLab. A copy travels in the weekly archive, so a restore on
new hardware doesn't need the old TPM.

## Considered options

- **An encrypted store in the manager's database, with a TPM-sealed key.** An earlier answer in the grilling,
  replaced by this one.
- **Plain files readable only by root.** Anyone with a copy of the disk would have them.

## Consequences

A spike must confirm this for Docker, rootful Podman and rootless Podman.
